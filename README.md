# סוכן רכבים - יד 2 (גרסת ענן)

אותו סוכן של התוסף, אבל רץ על GitHub Actions כל ~5 דקות, גם כשהמחשב כבוי.
ההתראות נשלחות למייל (דרך אותו Apps Script שכבר הגדרת בתוסף), ואפשר להוסיף גם טלגרם.

## הקמה (חד-פעמית, כ-15 דקות)

1. פותחים חשבון חינם ב-github.com (אם אין).
2. יוצרים Repository חדש: New repository, שם נייטרלי כלשהו (למשל `cars-agent`), **Public**.
   (ציבורי = דקות ריצה בחינם ללא הגבלה. בפרטי יש מכסה של 2,000 דקות בחודש, וזה לא מספיק לריצה כל 5 דקות.)
3. מעלים את כל הקבצים מהתיקייה הזו ל-Repository (Add file > Upload files, גוררים את הקבצים והתיקיות).
   חשוב שהקובץ יגיע בדיוק לנתיב `.github/workflows/scan.yml`.
   אם הדפדפן לא מעלה תיקייה שמתחילה בנקודה: Add file > Create new file, בשם כותבים `.github/workflows/scan.yml` והדבקת התוכן.
4. מוציאים את ההגדרות מהתוסף:
   chrome://extensions > מפעילים "מצב מפתח" > בכרטיס "סוכן רכבים - יד 2" לוחצים על "service worker" > לשונית Console.
   מדביקים שם את כל התוכן של `export-from-extension.js` ולוחצים Enter (אם Chrome חוסם הדבקה, כותבים קודם `allow pasting`).
   התוצאה (JSON עם הסוכנים וההגדרות) מועתקת ללוח.
5. ב-GitHub: Settings > Secrets and variables > Actions > New repository secret.
   Name: `CONFIG_JSON`  |  Secret: מדביקים את מה שהועתק. שומרים.
6. לשונית Actions > מאשרים הפעלה > בצד שמאל "yad2-agent" > Run workflow > mode = `check`.
   קוראים את הלוג. זו הבדיקה הכי חשובה: היא אומרת אם יד2 עונה ל-GitHub.
7. אם הבדיקה תקינה: מריצים שוב עם mode = `testnotify` ומוודאים שהגיע מייל בדיקה.
8. ב-mode = `scan` (או פשוט מחכים לריצה האוטומטית) נשמר בסיס התחלתי, ומעכשיו מקבלים מייל על כל מודעה חדשה.
9. משהים את הסוכנים בתוסף, כדי שלא תקבל כל מודעה פעמיים.

## טלגרם (אופציונלי, התראה מיידית לטלפון)
יוצרים בוט אצל BotFather, מקבלים token, ושולחים לבוט הודעה. את ה-chatId מקבלים מ-`https://api.telegram.org/bot<TOKEN>/getUpdates`.
מוסיפים ל-CONFIG_JSON את השדה: `"telegram": {"token": "...", "chatId": "..."}`

## הוספה / שינוי סוכנים
מוסיפים סוכן בתוסף כרגיל, מריצים שוב את `export-from-extension.js` ומחליפים את ה-Secret.
(סוכן חדש יקבל בסיס התחלתי בריצה הראשונה שלו.)

## דברים טובים לדעת
- GitHub מריץ cron "בערך" כל 5 דקות. בשעות עומס יש עיכובים וריצות שמדלגות, ולכן זה לא כמו סריקה כל 2 דקות בתוסף.
- בריפו ציבורי, שאין בו פעילות 60 יום, GitHub מכבה את התזמון. הוא שולח על כך מייל, ומפעילים מחדש בלחיצה (Actions > Enable workflow).
- הלוגים בריפו ציבורי גלויים לכולם, ולכן הם מכילים רק מספרים וסטטוס, בלי כתובות, שמות או טלפונים. ה-Secret עצמו מוסתר.
- אם יד2 תחסום את GitHub: ההתראה "הסוכן מתקשה לסרוק" תגיע אחרי 3 כשלונות רצופים. הפתרון הוא פרוקסי ישראלי (מוסבר בהערות ב-scan.yml) או שרת קטן בישראל.
- בדיקות אוטומטיות: `node test/run.test.js` (נתוני דמה, בלי רשת).
